    Write a description for a while loop.

a while loop is when we want to repeat something so we start
with the word "while" and write the condition we want to put
so each time this condition happens it will repeat and repeat
until something breaks this loop. We also have "While true" which
is the same but this applies only if the condition is true

"for variable in other_variable" we can also print that like a list.
